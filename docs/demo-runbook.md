# 比赛演示与提交收尾

当前主线：**一次 Ethereum 异动线索调查，输出可复查的事实、解释与未知项。** 用户任务及付费意愿仍是假设；不能声称已经找到客户、比通用 AI 更快或避免了亏损。

## 两分钟讲稿

**0:00–0:20：问题。** “看到一条‘某钱包在卖 ETH’的消息，交易量大还不足以说明发生了卖出。我们做的是一份可以沿着交易、区块与池事件复查的调查报告，让投研或运营人员核对判断依据。这类人员是候选用户，我们尚未验证采用或付费。”

**0:20–0:55：真实量化。** 打开 `/report`，输入观察钱包，选择规则解释，生成报告。展示同一观察的区块、原生 ETH/USDC 持仓、Chainlink 行情、单池相邻两个五分钟的总卖出额、基线与倍数。“这是指定池总卖出，不是全市场净流出；正常窗口也如实报告，不造 Risk 91。风险分数是未校准规则，Confidence 不是下跌概率。”

**0:55–1:25：复查证据。** 展示解释、未知项与 Etherscan 引用。另打开 `/investigate`，核验固定本池卖出案例：“该事件确认 0.198 WETH 流入池，517.590594 USDC 流出池；它不能证明钱包全笔净卖出或交易意图。”历史交易与当前卖压窗口是独立核查，不拼成同一事件或预警因果。

**1:25–1:45：调查边界。** 若真实模型已经实际验收，选择 AI，说明它接收工具已经核验的事实目录，输出有引用且明确标为推断的解释；引用校验不等于原因正确。若仍缺凭据，直接说明“AI 接线已完成，在线调用尚未验收”，不要表演假模型结果。本实现不是自主工具选择 Agent。

**1:45–2:00：交付与下一步。** “交付是一份有出处、有方法、有未知项的报告。自动保护保留为独立 Mock/Fork 实验，报告不直接控制资金。接下来要验证目标用户是否愿意把一条真实线索交给我们复核，以及工具相对现有办法是否提供增量。”

## 演示步骤

1. `pnpm install --frozen-lockfile`；配置本地 `.env.local` 的 RPC；`pnpm dev`。
2. 首先打开 `/report`，钱包例子：`0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045`。这是公开观察地址，不是团队用户或已授权钱包。
3. 规则模式生成真实报告，检查模式、完成时间、区块时间、范围与未知项。不能预设分数或异常倍数。
4. `/investigate` 输入 `0x310948594828e864aff5f1bc133968b80889379ec66091e734a6758bf8abc9e9`，核对本池日志 12。交易日期和当前窗口分别展示。
5. 反例输入 `0x19b45706e3877b8cb19133dbdc6f8013a5a4a033495e7b070c84977620348e8a`，说明外层原生 ETH 转账不等于指定池卖出。节点需支持历史交易、回执和区块读取；当前 reader 对所有交易还会在该历史 blockHash 核验池/ERC20 元数据，因此也需要历史 `eth_call`。
6. AI 配置齐全后另行验收正常、证据不足与请求/输出失败。密钥不出现在页面或录屏中。
7. 如展示 `/guardian`，先说“独立 Mock/Fork 实验”。不重置 journal，不为重复演示重新广播，不把实验交易 hash 当成主网证据。

## 网络失败的处理

页面报错就如实保留报错，不能自动替换成旧结果。可以手动打开 [已保存真实案例](demo-cases.md)，明确说“这是注明采集时间的历史实测记录，当前网络失败；不是本次在线结果”。本轮完整 CLI 已成功读取一次，其他公共 RPC 测试亦有失败，不能据此保证稳定。

dRPC 实测抓到限流错误；PublicNode 实测在历史合约读取返回错误。比赛现场需配置支持所需历史数据的专用 RPC。不要连续多人重复查询公共节点，不能声称更换任意 RPC 都有效。节点 URL 不录入公开材料或视频。

## 提交清单

- [ ] 真实 HTTP 报告在线成功，RPC 配置和运行步骤可复现。
- [ ] 真实 AI 正常/不足/失败三类记录；未完成时披露，不能写为已上线。
- [ ] 实际录制主线视频，核对可播放、画面可读、声音及时间；截图和讲稿不能代替录像。
- [ ] README、PPT、视频使用一致口径；模型、历史、规则、Mock/Fork 分别标注。
- [ ] 用户明确确认后提交 Git 改动、push、PR 与 main 合并；远端 CI 和本地版本同步再核对。
- [ ] 按主办方实际表单提交并取得成功回执；尚未拿到正式清单/回执不能称已提交。

BOT 部署、主网自动交易、持续监控与收益预测不进入本轮收尾。验收和提交状态见执行计划；不能把此清单的存在当作执行完成。
