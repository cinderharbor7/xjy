# 外部 Agent 驱动的 Ethereum 异动报告（已批准执行）

## Goal And Boundaries

网站提供真实数据、确定性指标、来源和报告呈现；外部模型负责选择工具、综合调查、提出假设与表达不确定性。真实报告流程不再由网站请求内置模型，不要求网站保存模型 API Key。2026-10-08 用户批准执行；此文记录实施与验收状态。

沿用原生 HTML/CSS/JavaScript、瑞士国际主义与 VERDANT 配色；以首页和 ETH 详情页的数据为主。报告聚焦 ETH 市场及生态观察，不把 Binance 行情称为 Ethereum 链上交易，也不把静态流动性或 TVL 称为资金流出证据。Guardian、Policy、签名、存证及收藏不进入 Agent 工具权限。既有链上核验入口继续独立存在，本轮不新增采集范围。

已确认接入方式：用户选择 WebMCP，外部 Agent 打开网页后调用页面工具；不建设标准远程 MCP 服务。使用顶层页面工具注册，复用现有数据读取和校验逻辑；浏览器不支持时明确显示工具不可用，不回退调用内置模型。此前提到的论文尚未提供，所有现有公式仅标为工程统计，不标为论文方法。

## P-001 有来源的调查数据快照

复用 `server/fingerprint.js` 的 `market()`、`detail('ETH', 1|7)` 和 `web/fingerprint/data.js` 的统计逻辑，增加独立的调查快照与来源校验层。不要抓取页面四舍五入后的文字或视觉指纹参数作为事实。快照记录 snapshotId、生成时间、各源观测/采集时间、单位、窗口、状态及数据项引用 ID；这是多源采集批次，不是同一时间或同一区块的原子快照。

已核实可复用的数据：

| 数据 | 当前来源与接口 | 边界 |
| --- | --- | --- |
| ETH 现价、24h 涨跌、成交额、成交笔数、高低价、振幅；其他首页币种的比较背景 | `/api/market`，Binance USDT 现货对 | 单交易所；USDT 不等同 USD；不是链上流量 |
| 24h/7d 已收盘小时 K 线、成交额、主动买入报价资产成交额 | `/api/detail?coin=ETH&days=1或7` | 不把未收盘 K 线纳入统计；标明实际样本数 |
| 小时收益率日化波动率、区间最大回撤、主动买入占比 | 现有 candleStats 与 detail 派生计算 | 公式、窗口、输入引用同时提供，不是预测概率 |
| 买卖价差、±1% 买卖盘深度、盘口不平衡 | Binance 返回的 100 档盘口 | 只覆盖返回档位；盘口和 K 线采集时间不同 |
| 返回池数量、流动性合计、最大池、24h 买卖笔数 | DEX Screener WETH 返回集 | WETH 包装资产；不是全网覆盖，笔数不等于净卖出额 |
| Ethereum 链 TVL | DefiLlama | 链级静态值；没有历史序列时不能判断 TVL 下降 |
| 全市场恐惧贪婪指数 | Alternative.me | 市场背景，不是 ETH 专属情绪 |
| 新闻标题、URL、来源域名、GDELT 收录时间 | GDELT，24h 最多 20 篇 | 无正文；收录时间不保证等于发布时间；标题不能证明因果 |
| go-ethereum Stars、Forks、Issues、最后推送时间 | GitHub | 仓库背景，不代表协议安全或即时开发活跃度 |

当前服务已有 live/stale/unavailable 状态和缓存，计划保留语义并补齐每组指标的来源映射。真实报告不接受 demo 数据；stale 数据只能作为明确标注的历史背景，不能支撑“当前”事实；缺失为 null，不能补 0。上游缺失可记录为“证据不足”，不生成替代数值或静默 Mock。所有用于公式的数值、时间与分母需边界校验。

验收：相同快照反复读取不重新采集；新采集生成新 ID；来源不可用、空 K 线、样本不足、零分母及过期数据均可辨认；模型不能修改快照事实。

## P-002 外部 Agent 工具与受校验的报告结果

以下是待实现的工具接口建议，不是已发布 API：

| 工具 | 输入 | 输出与作用 |
| --- | --- | --- |
| `create_eth_snapshot` | windowDays: 1 或 7 | 显式采集；返回 snapshotId、覆盖情况、时间与数据目录 |
| `get_eth_snapshot` | snapshotId | 读取同一次快照中的首页 ETH/市场背景与 ETH 详情数据，不重复采集 |
| `get_eth_indicator_definitions` | 无 | 单位、公式、输入字段、适用窗口与限制；未提供论文前不含论文背书 |
| `get_eth_evidence` | snapshotId、限定分组 | 返回行情/盘口/DEX/TVL/新闻/仓库证据及稳定引用 ID，支持定向查看 |
| `submit_eth_report` | snapshotId、结构化报告 | 校验后交回当前调查；模型只能提交判断与引用，不能覆盖原始数据或执行交易 |
| `get_eth_report` | reportId | 读取已接受的报告及引用快照，供模型与页面核对 |

外部 Agent 的工作路径为：建立快照 → 查看数据与指标定义 → 针对可疑维度取证 → 比较解释和反证 → 提交报告。没有异常也是有效结果。页面显示实际调用记录，不预先播放“Agent 正在思考”的虚构流程。

拟定报告产物为独立、带版本的 ETH 调查 DTO：reportId、snapshotId、asset、窗口、生成时间、数据覆盖、摘要、观察结果、假设与支持/反驳引用、未知项、下一步核查建议。观察状态建议区分“发现异常线索 / 未发现明确异常 / 数据不足”。具体枚举在实施前冻结。不把旧钱包必填的 OnchainReportSchema 强行填成无钱包市场报告，不更改 Guardian 的 RiskAnalysis/PolicyDecision。第一版不制造综合 Risk Score 或概率型 Confidence；定性证据充分程度需解释依据。

提交校验检查结构、长度、快照存在性、引用 ID 属于本次快照、事实引用与时间范围；事实数值由系统附加，模型只作解释。外部文本以纯文本安全呈现。校验通过表示格式与引用有效，不等于假设因果已验证。网页/新闻内容始终视为资料，不能获得工具权限。

真实报告入口移除内置模型选项及请求路径；旧 AI 模式请求应显式拒绝，不自动改成规则报告。先检查全部调用方，再冻结具体错误合同。保留其他实验模块的边界，不把整个仓库的研究/Mock Agent 一并删除。

验收：站点无模型凭证也可提供数据和接收外部报告；未知快照、伪造引用、越权写入、恶意 HTML 均被拒绝或安全呈现；未连接 Agent 时只能显示数据准备情况，不能出现假报告。真实外部客户端端到端调用另行验收，单元 Mock 不能代替。

## P-003 A4 与 JSON 共用的真实报告页面

`/report` 成为 ETH 调查工作台。建议以 ETH 与 24h/7d 窗口为输入，不要求钱包；流程为准备数据、等待外部 Agent、接收校验、阅读报告。首页与 ETH 详情页仍链接此入口。页面区分“浏览器不支持 / 工具已注册 / 收到实际调用 / 报告已返回”；工具已注册不代表 Agent 已连接。

默认 A4 阅读视图，内容顺序：报告标题与时间 → 核心结论及覆盖程度 → 关键数据 → 异常线索与解释 → 支持/反驳证据 → 未知项 → 来源与方法。桌面纸张居中、细线分区与留白；移动端宽度自适应、单列排版，保留纸面感而非缩小整个 A4 导致文字无法阅读。长内容自然延展，不裁切成固定一页。维持现有配色与瑞士国际主义。

页首提供 A4 / JSON 切换；两种视图读取同一份已校验结果。JSON 展示完整结构与来源，可复制或下载。切换不重新请求数据、不调用模型、不改变快照。未完成、校验失败和仅有历史报告时分别明确显示，不能拿旧结果冒充本次。

验收：工具回传结果可以在当前页面呈现；两种视图内容一致；引用可追溯；切换无网络副作用；移动端布局由用户视觉检查，代理只做 DOM/构建与功能测试，不启动浏览器或截图。
