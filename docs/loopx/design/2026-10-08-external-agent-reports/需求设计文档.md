# WebMCP 真实报告设计文档

## 二、需求信息
### 2.1 背景
来源：用户批准 docs/loopx/plans/2026-10-08-external-agent-reports.md，选择 WebMCP。提案同目录且已获方向授权。
### 2.2 范围
只更改真实报告、快照和外部工具。保留首页、ETH 详情、Guardian、收藏与存证能力。论文未提供，延后；不修改密钥、运行进程或发布 Git。

## 三、概要设计
### 3.1 方案总述
同源 HTTP 只读采集 → 页面会话持有快照 → WebMCP 六工具 → 外部 Agent 回传结构化解释 → 引用校验 → 同数据 A4/JSON。
### 3.6 专项设计检查
api-designer：严格参数，旧 AI 410，不静默降级。architecture-designer：无推理服务、无新存储、受限会话生命周期。

## 四、详细设计
### 4.1 快照与报告
**Data Contract D-001**：snapshotId、ETH、窗口、采集时间、各来源证据组与状态。来源各有时间，非原子链上快照；live/stale/unavailable 分开，缺失 null，无 demo。计算值沿用现有公式，不以模型覆盖事实。
**Data Contract D-002**：外部报告只提交结论、观察、假设、证据 ID、未知项及后续核查。快照、报告 ID、接受时间由网站生成。严格 Zod 与引用归属检查，不能把格式通过称为内容真实。
#### 4.1.4 边界条件
空样本与除零不生成指标；无 live 证据只能提交数据不足；不可用证据不能支持事实。陈旧数据可引用为背景，不成为当前事实。当前会话只保留一个快照/报告，重新采集清空旧状态，失败不能展示旧结果。重复相同提交幂等，不同报告拒绝覆盖，用户重新准备数据开始新调查。
#### 4.1.5 不变行为
原数据源缓存政策保持；网站不新增任意 URL 抓取。原生 ETH/WETH、USDT/USD、链/协议 TVL 边界保持。
### 4.2 工具与页面
**Interface Contract D-003**：工具仅在 /report 顶层注册于 document.modelContext；不支持时明确提示。离开页面注销，保留闭包也拒绝执行。注册失败清理已注册工具。工具 schema 与执行校验共用；输入长度/数组数量有界。
**Behavior Contract D-004**：内置真实报告 AI 请求以 AI_MODE_REMOVED / HTTP 410 拒绝，RPC 与模型调用前停止；RULES 旧合同保留。研究模块的 AI 类不删除。
**Workflow Contract D-005**：A4/JSON 同源，外部 Agent 的文字为未独立核实解释；实际调用日志只在调用时产生，不伪装后台推理。当前页面内存保存，刷新丢失，可复制/下载 JSON。
#### 4.2.4 边界条件
并发采集拒绝；处理中不能提交；过期快照或报告 ID 拒绝；卸载中完成的请求不回写。非 HTTP(S) 来源 URL 拒绝，外部文本转义。无写链权限。
#### 4.2.5 不变行为
原生前端及主题不变，用户做视觉验收；不调用浏览器工具。无持久化事件或真实交易改变。

## 七、接口设计
GET /api/eth-report-snapshot?days=1|7：仅限现有配置的同源本机入口，200 快照、400 非法参数、403 来源不符、503 数据异常。响应 no-store；现有上游 TTL 缓存不因该头改写。文档见 docs/webmcp-reports.md。WebMCP 工具只处理页面内存会话，不接受会话 token/文件路径/任意 URL。

## Planning Handoff
按批准计划执行三片；实现可选择内部文件分解与界面细节，不改变六工具范围。论文、跨页持久化和远程 MCP 留待新授权。

## 十一、QA
无阻塞性待确认项，论文明确延后。测试映射：快照语义/边界 D-001；伪造引用/重复提交 D-002；注销/注册失败/并发 D-003；无模型/RPC 请求 D-004；A4/JSON一致与 HTML 转义 D-005。真实浏览器工具调用仍需用户现场验收，不以模拟测试替代。
