# 保留 PositionState，通过独立只读响应接入 Aave

> 历史扩展设计：保留当时的 Aave 里程碑裁决；它不再定义 Guardian 核心 Domain。有效实现现位于 src/extensions/aave/，公开只读接口保持。当前主架构见 [Guardian 设计](../2026-10-06-risk-guardian/需求设计文档.md)。

## 摘要与已确认裁决

用户确认沿用 camelCase PositionState，查询响应独立带行情和证据；没有借款时不制造 PositionState。新增 AavePositionAdapter、POST /api/position、/position 页面，保留 Mock 救援入口。本轮只读主网 Aave V3 Core，不创建测试资金仓位、不签名、不执行还款。

## 方案与边界

公共接口新增 PositionSnapshot 的 ACTIVE / NO_DEBT 两种明确结果，既有 PositionState 不改变。Adapter.getPosition 仍供 B 使用；getSnapshot 供只读集成与 D 使用。读取主网 chainId、固定区块与 provider 的 Pool/Oracle，在相同区块读取账户与价格，来源地址来自固定版本官方地址包。

有债务时附带 7200 区块价格变化与实际时间；历史读取失败报错。无借款返回 position=null 和链上证据。只读调用不产生 txHash，字段预留可选但本轮不伪造；测试钱包的真实 Borrow tx 单独记录。

## 取舍与兼容性

不迁移成 snake_case，因为用户已确认保留冻结契约。拒绝以 Infinity、零或巨大 sentinel 冒充有意义 HF，因为无借款结果已经获得明确裁决。不把真实仓位送入 Mock Executor。行情采用小型固定区块窗口，避免额外数据库、行情服务或精确 24h 搜索；披露实际时间。

## 专项检查与边界场景

API 输入输出 strict validation；只允许服务端环境配置 RPC，不接受请求提供 RPC 地址。错误消息不泄漏 RPC URL/凭据。错误网络、缺配置、无效地址、零价格、异常 HF、读取超时与部分失败明确终止。重复/并发均为独立无状态查询，不写链或持久化，旧 Mock 接口不变。保留过去版本行为，无数据迁移、备份或兼容 shim。
