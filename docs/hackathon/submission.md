## 一、项目介绍（对应 5.2 第 1 项）

- **队名 / 成员**：【TBD：队长填写】
- **项目名称**：Risk Guardian —— 可复查的 Ethereum 异动调查原型（附受限保护执行实验）
- **目标用户（假设，未验证）**：承担 ETH 异动核验、需要把判断交给他人复查的投研 / 运营人员。
- **解决的问题**：社媒/群聊出现带交易哈希的 ETH 大额异动消息时，核验者需要分清"确认事实、证据支持的解释、证据缺口"，交出别人能复查的判断。公开误读案例（Cointelegraph 对 Kanro 多签转账的更正）证明这类核验工作真实发生。
- **核心功能**（均已在仓库验收，性质分别标注）：
  1. **真实只读报告**（真实主网只读）：`/report` 输入钱包，同一快照输出持仓、Chainlink 行情、相邻 5 分钟单池卖压、规则风险、事实/解释/未知项与链上引用；**显式选择 RULES 或 AI 调查**——AI（DeepSeek）已在真实快照、受控证据不足、无效凭据三类实测通过，在线 HTTP 与浏览器链路各成功一次；缺配置/失败明确报错不回退规则；固定工具读侧＋模型解释，非自主 Agent。
  2. **量化观察与规则分析**（真实主网只读）：相邻 5 分钟窗口单池 gross sell-pressure 对比，确定性 Risk/Confidence 输出，逐条引用与固定未知项。
  3. **具体交易证据核验**（真实主网只读）：输入 txHash，输出外层交易事实、固定池 Swap 方向与精确数量、中文解释与未知项；入口 `/investigate`。
  4. **受限保护执行实验**（独立 Mock 演示，Fork 本轮未运行）：用户预设六条硬规则批准 → 单向减仓 → 独立重读 → 八项效果验证；一次事件最多一笔 swap，重复请求 409 拒绝。
- **比赛期间完成的工作**：上述异动调查（量化观察＋交易核验）、真实只读报告与显式 AI 调查接线、受限保护实验与报告存证为本次比赛新增；统一原生前端与货币指纹设计体系为既有基础（沿用来源见下节）。【TBD：队长按实际参赛历史最终确认新增/沿用划分】
- **如实披露**：AI 为显式模型解释而非自主调查 Agent（不做动态工具选择）；公共 RPC 稳定性未通过（专用节点待配置）；使用者/采用/付费均为假设；通用 AI 对照实测（AC-006）尚未完成，不声明相对通用 AI 的优势；不做主网自动交易、价格预测、身份鉴定。

## 二、代码与运行说明（对应 5.2 第 2 项）

- **代码仓库**：【TBD：队长填写可访问的仓库链接；当前远程 origin 为团队私有仓库】
- **环境依赖**：Node.js ≥ 22.13（推荐 24 LTS，使用 node:sqlite）、pnpm 11（仓库固定 11.7.0）。
- **启动步骤**：

```bash
pnpm install
pnpm dev        # http://127.0.0.1:3000，默认 MOCK，无需 RPC / 私钥 / 钱包连接
```

- **真实主网只读查询**（可选）：在 `.env.local` 配置 `ETHEREUM_RPC_URL`（主网 chain id=1，需支持历史区块、日志与 `blockHash + requireCanonical`）后：

```bash
pnpm data:analyze --wallet 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045 --json   # A→B 单次只读分析
# 或启动服务后使用 /report（完整报告，显式 RULES/AI）与 /investigate（单笔核验）
```

- **显式 AI 调查**（可选）：服务端 `.env.local` 配置 `LLM_API_KEY / LLM_API_URL / LLM_MODEL`（DeepSeek 实测用 flash、显式关闭 thinking），页面 `/report` 显式选择 AI；浏览器不接收密钥，缺配置明确拒绝、不回退规则。配置说明见 [docs/onchain-report.md](../onchain-report.md)。
- **检查命令**：`pnpm typecheck`、`pnpm test`、`pnpm build`（基线 2026-10-07 23:34 本分支复跑：1043 passed / 6 skipped，跳过项需显式 Fork 配置）。
- **主要入口**：`/` 资产观察 ｜ `/report` 真实只读报告（RULES/AI 显式选择）｜ `/investigate` 交易核验 ｜ `/guardian` 保护实验 ｜ `/risk-lab` 风险研究（Mock fixture）｜ `/attestations` 报告存证 ｜ `/collection` 指纹收藏。
- **沿用组件 / 素材来源**【TBD：队长最终确认清单】：
  - 统一原生前端（HTML/CSS/原生 JS/Tailwind）与货币指纹注册表、暖纸色/深绿/陶土色设计体系：既有 xjy 基础，本次沿用；
  - 链上交互：viem；数据合同：Zod；测试：vitest；构建：Vite；
  - 数据来源：Ethereum 主网 RPC、Chainlink 预言机、Uniswap V3 池事件；示例钱包为公开地址，不代表项目持有或控制。
