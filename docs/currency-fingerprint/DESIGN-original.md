# Currency Fingerprint / 货币指纹

依据：原始数据与技术.md 与本次用户旅程。全新独立项目，不复用 xjy。

设计技能：https://github.com/anthropics/skills/tree/main/skills/frontend-design
已安装为 anthropic-frontend-design。

## 设计决策

主题是可收藏的数字标本。将视觉预算集中在由数据驱动的有机指纹，页面用安静的实验室标注和明确的阅读顺序托住它。避免把交易终端的密集指标直接搬上首页。

最终风格按用户最新要求改为瑞士国际主义。色板：白 #fafaf8、浅灰 #f2f2ee、黑 #171717、线灰 #d6d6cf、操作红 #d72e24、正向绿 #28744e。渐变只保留在表达数据的指纹与情绪刻度中。

字体：Helvetica Neue / Arial 搭配中文 PingFang SC / Microsoft YaHei，不依赖远程字体；数字使用 tabular-nums。首页标题 54–78，详情标题 46–58，模块标题 21–30，正文 13–14，来源标注 10–12。主标题紧字距，强调清晰字重对比。

布局：横向主导航；5:7 的首页信息与图形分区；下方两列横向币种行。详情左侧币种信息，右侧大图，下方价格、维度和来源。直角、左对齐、规则分隔线；移除点阵、装饰轨道与非必要阴影。

```
品牌                     探索 / 我的收藏 / 读懂指纹      钱包
焦点币种介绍              大型互动指纹
关键行情                  数据维度标注
指纹图鉴                  搜索 / 筛选 / 排序
动态图 + 币种 + 数据      动态图 + 币种 + 数据
```

已复核设计意图：不复刻已有 xjy Organic；主色与排版使用瑞士国际主义，指纹保留数据颜色。用户要求动态币种列表，使用共享动画循环和可见性检查控制性能。键盘焦点、减少动态效果、移动端单列为基础要求。

验收边界：用户最新指示“你不做视觉检查，我来做视觉检查，你根据反馈修改”。此前初版做过桌面浏览器检查；切换瑞士风格后停止截图、浏览器检查和视觉验收，仅执行构建、代码、接口和合约验证。新风格等待用户反馈。

## 实现边界

原生 HTML/CSS/JS，Tailwind 本地编译，Vite 仅作构建工具；Node 内置 HTTP 提供同源只读数据代理及缓存。没有 React、数据库、登录系统或外部密钥。

NFT：ERC-721，图像、数据快照、来源标记写入 data URI；指定 BOT Chain Testnet（968 / 0x3c8）。UI 必须等交易回执成功后才计入收藏；未配置合约或未连接钱包时给出明确状态。公开测试网部署需用户钱包授权和测试 BOT，本次仅执行本地 EVM 验证。RPC https://rpc.bohr.life 已只读核验 Chain ID，浏览器 https://scan.bohr.life。
