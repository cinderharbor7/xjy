# 货币指纹

## 数据来源

DEX Screener + Binance + DefiLlama + GDELT + GitHub + Alternative.me

| 数据源                                 | 可获取的核心数据                                                         |        API Key | 免费额度                | 速率限制                                                                               | 建议抓取频率                     | 公开性/注意事项                                      |
| ----------------------------------- | ---------------------------------------------------------------- | -------------: | ------------------- | ---------------------------------------------------------------------------------- | -------------------------- | --------------------------------------------- |
| **DEX Screener**                    | Token 价格、DEX 成交量、1h/6h/24h 涨跌、买入笔数、卖出笔数、流动性、FDV、市值、交易池、Pair 创建时间 |            不需要 | 免费                  | Token/Pair 主要接口约 **300 req/min**；部分接口 **60 req/min**                               | 30–60 秒                    | **A**。非常适合作为 DEX 行情和流动性主数据源                   |
| **Binance Public API**              | K线、最新价格、24h 行情、成交记录、Bid/Ask、Order Book、市场深度、主动买卖量                |      市场数据通常不需要 | 免费                  | 按 **Request Weight** 计算；Spot 常见总上限约 **6000 weight/min/IP**，以 `exchangeInfo` 实时规则为准 | Order Book 5–30 秒；K线 1 min | **A**。适合 BTC、ETH 等已上 Binance 的币，不适合覆盖所有 Token |
| **DefiLlama Public API**            | TVL、历史 TVL、Chain TVL、协议类别、部署链、部分价格及 DeFi 基本面数据                   | Public API 不需要 | 免费 Public Endpoints | 免费接口没有统一公开的固定 QPS，应避免高频轰炸                                                          | 15–60 min                  | **A**。DeFi 项目的基本面数据非常有价值                      |
| **GDELT**                           | 全球新闻文章、币种提及量、媒体来源、发布时间、新闻热度、关键词搜索结果                              |            不需要 | 免费                  | 官方存在动态限流，没有统一固定 QPS                                                                | 5–15 min                   | **A**。适合抓新闻，再自行用 NLP/LLM 分析情绪和事件              |
| **GitHub Public API**               | Stars、Forks、Issues、Commits、Contributors、代码增删、最后更新时间等公开仓库数据       |            不需要 | 免费                  | 未认证约 **60 req/hour/IP**                                                            | 1–6 h                      | **A**。仅针对公开仓库；认证后额度更高，但认证模式就属于 B 类            |
| **Alternative.me Fear & Greed API** | Crypto Fear & Greed Index、历史恐惧贪婪指数                               |            不需要 | 免费                  | 未公布固定硬性限速                                                                          | 1–6 h                      | **A**。展示数据时需要注明来源                             |


|维度|建议字段|来源|
|---|---|---|
|**价格**|`price`、`high`、`low`、`return_1h`、`return_6h`、`return_24h`|DEX Screener / Binance|
|**成交**|`volume_1h`、`volume_6h`、`volume_24h`、`trade_count`|DEX Screener / Binance|
|**DEX交易行为**|`buys`、`sells`、`buy_ratio`、`sell_ratio`|DEX Screener|
|**DEX流动性**|`liquidity_usd`、`pool_count`、`largest_pool_liquidity`|DEX Screener|
|**市场微观结构**|`best_bid`、`best_ask`、`spread`、`depth_05pct`、`depth_1pct`|Binance|
|**买卖压力**|`taker_buy_volume`、`taker_sell_volume`、`orderbook_imbalance`|Binance|
|**波动率**|`volatility_1d`、`volatility_7d`、`max_drawdown`、`return_zscore`|Binance 原始 K 线自行计算|
|**DeFi基本面**|`tvl`、`tvl_change_1d`、`tvl_change_7d`、`chain_tvl`、`chain_count`|DefiLlama|
|**新闻热度**|`news_count_1h`、`news_count_24h`、`news_count_7d`、`unique_publishers`|GDELT|
|**新闻评价**|`sentiment`、`positive_ratio`、`negative_ratio`、`event_type`、`importance`|GDELT + 自己 NLP/LLM|
|**开发活跃**|`stars`、`forks`、`commits_7d`、`commits_30d`、`contributors`、`last_commit`|GitHub|
|**市场环境**|`fear_greed_index`|Alternative.me|

## 可视化形式

**[shader-park-core](https://github.com/shader-park/shader-park-core)** 通过颜色、形状、变换，展现该币种的数字指纹

[3d-force-graph](https://github.com/vasturiano/3d-force-graph) https://github.com/jacomyal/sigma.js  展现社交媒体观点交织、冲突网络
